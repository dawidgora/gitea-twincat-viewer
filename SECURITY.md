# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through a
[GitHub Security Advisory](https://github.com/dawidgora/gitea-twincat-viewer/security/advisories/new).
Do not disclose the vulnerability publicly until it has been reviewed and a
fix or mitigation is available.

Include the affected version, a description of the impact, and steps to
reproduce the issue when possible. We will acknowledge reports and coordinate
next steps through the advisory.

For general questions, use the repository's
[GitHub issues](https://github.com/dawidgora/gitea-twincat-viewer/issues).

## Supported versions

Security fixes are provided for the latest version on the `main` branch.
