# Code of Conduct

## Our standards

We are committed to a welcoming, respectful, and constructive community.
Contributors are expected to:

- Be considerate and respectful.
- Give and accept feedback professionally.
- Focus on what is best for the project and its users.
- Respect differing viewpoints and experiences.

Harassment, discrimination, personal attacks, trolling, and other disruptive or
unprofessional behavior are not acceptable.

## Enforcement

Project maintainers may remove comments, close discussions, or take other
action when this code of conduct is not followed. Report concerns privately to
the project maintainers through GitHub.
